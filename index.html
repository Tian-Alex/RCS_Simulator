這是什麼？

這是一個在瀏覽器中執行的火箭姿態控制模擬器。火箭在外太空中會因為擾動而翻滾，姿態控制系統的任務就是利用冷氣推進器（RCS）產生的力矩，把火箭轉到並維持在目標方向。完整方程式與出處見 docs/equations.md，新手教學見 docs/getting-started.md。

快速入門（三分鐘）

  1. 按左側「中型（預設）」選擇參考案例。
  2. 按頂列「開始」即時播放，觀察 3D 火箭如何從翻滾收斂到目標姿態（半透明白色框架）。
  3. 按「快轉完成」直接算到底，再看下方圖表與「效能指標」分頁的穩定時間與推進劑消耗。
  4. 切換「控制器」面板的控制律（PID / LQR / Quaternion PD）與「調變器」模式（PWPF / PWM / 連續），比較收斂快慢與推進劑用量。

怎麼看圖表

  • 姿態：roll/pitch/yaw 隨時間變化，應收斂到目標角。
  • 姿態誤差角：總誤差越小越好；PWPF/PWM 模式會殘留小幅極限環（開關推力的固有現象）。
  • 角速度：應收斂到 0 附近。
  • RCS 開關歷程：每具推力器的點火時機，愈密代表控制器愈忙。
  • 相圖：誤差角 vs 角速度的軌跡，收斂螺旋拉向原點代表穩定。

所有 2D 圖表：滾輪縮放、拖曳平移、雙擊重設；游標移到線上會顯示對應時間點的數值。

參數調整建議

想觀察…調這裡
更快的收斂控制器面板 → 增大 Kp（PID/QPD）或 Q（LQR）
抑制震盪增大 Kd（PID/QPD）或 Q 的角速度項（LQR）
對抗常值擾動增大 Ki（PID），或加大積分上限
推進劑消耗調變器 → PWPF 門檻 Uon、或改用理想連續模式對照
真實閥門行為推力器卡片 → 開關延遲、最小衝量、占空比

推力器怎麼設定？

左側「RCS 推力器」面板改為卡片式：位置可用「站位＋時鐘角＋半徑」（時鐘角 0° = +Y、90° = +Z，站位沿縱軸，+X = 鼻錐方向）或直接改 xyz，兩邊自動同步；方向可按 ±X/±Y/±Z 快選或輸入向量。可新增／刪除推力器，在 3D 視圖點噴嘴可快速選取。

座標系

箭體縱軸為 +X（鼻錐方向），Y/Z 為橫向軸；3D 視圖中的紅色箭頭與「X（鼻錐方向）」標籤即縱軸。姿態顯示為 roll–pitch–yaw（3-2-1 Euler 角）。
