# 新手快速入門指南

本指南寫給第一次接觸姿態控制模擬的使用者。讀完後你會知道：這個模擬器在做什麼、每個面板在調什麼、怎麼跑出第一個結果、以及如何判讀圖表。數學細節請再搭配 [docs/equations.md](equations.md)。

## 這個專案在做什麼？

一枚在外太空的火箭（例如衛星入軌後的上面級）不會自己「站好」——任何殘留轉速或擾動都會讓它慢慢翻滾。姿態控制系統的任務是：

1. **量測**：陀螺儀與姿態感測器告訴我們火箭現在「朝哪裡、轉多快」。
2. **決策**：控制律（PID / LQR / Quaternion PD）計算「需要多大的力矩」才能轉向目標。
3. **執行**：冷氣 RCS（reaction control system，反應控制系統）推力器點火產生力矩。

本模擬器把這整個閉迴路完整模擬出來：6 自由度剛體動力學、可開關的推力器（含延遲、最小衝量、占空比限制）、推進劑消耗，以及 3D 動畫與各種圖表。

## 三分鐘跑出第一個結果

1. 開啟網頁後，左側已有預設的「中型上面級」案例。
2. 按「開始」：3D 視圖中的火箭會從初始翻滾狀態開始被 RCS 拉回目標姿態（半透明白色框架）。
3. 按「快轉完成」直接算到模擬結束。
4. 切到「效能指標」分頁：看穩定時間（多久進入帶寬）、最終誤差角、推進劑消耗。

### 座標系（重要）

- 箭體**縱軸是 +X**，也就是鼻錐方向；3D 視圖中紅色箭頭與「X（鼻錐方向）」標籤標示。
- Y、Z 是橫向軸。
- 姿態以 roll–pitch–yaw 顯示（3-2-1 Euler 角）：roll 繞 X、pitch 繞 Y、yaw 繞 Z。
- 推力器「方向」是**作用在箭體上的力**的方向（排氣方向相反）。

## 左側參數面板說明

### 模擬設定
- **模擬時長**：算多久。**物理步長**：積分精度（越小越準越慢）。**控制週期**：控制器多久更新一次指令。**記錄間隔**：圖表資料取樣密度。
- **穩定判據帶寬**：誤差小於此值且不再超出，就視為「已穩定」。

### 載具與慣量
- 乾質量／推進劑質量、箭體長度與半徑。
- **轉動慣量**（Ixx/Iyy/Izz）：對某軸「難轉」的程度。滾轉（繞縱軸）通常最容易。
- **慣性積**（Ixy 等）：箭體質量分布不對稱時不為零；設 0 表示對稱。
- 質心位置：推力器的力矩臂＝安裝位置−質心，會直接影響力矩大小。

### 初始條件與目標姿態
- 初始姿態／角速度：模擬起點（例如設定大角速度＝模擬「翻滍中的火箭」）。
- 目標姿態：希望火箭最後指向哪裡。

### 控制器（三種控制律）
| 控制律 | 原理 | 適合 |
|---|---|---|
| PID | 比例＋微分＋積分回授，直觀好調 | 入門、抗常值擾動 |
| LQR | 以最佳控制解 Riccati 方程求增益 | 系統化設計、多軸耦合 |
| Quaternion PD | 直接用四元數誤差，全域有效 | 大角度機動 |

調法速記：**Kp/Q↑ → 更快；Kd（或 Q 的 ω 項）↑ → 更不震盪；Ki ↑ → 穩態誤差更小但易過衝**。

### 調變器（連續指令 → 閥門開關）
- **PWPF（脈寬脈頻）**：最接近真實航太作法；會殘留小極限環。
- **PWM（脈寬）**：固定週期開關。
- **理想連續**：推力可連續調節的對照組（驗證控制器本身）。

### RCS 推力器（卡片式）
每具推力器一張卡片：
- **位置**：可用「站位（沿縱軸 X）＋時鐘角（0° = +Y、90° = +Z）＋半徑」，或直接改 px/py/pz——兩邊自動換算。
- **方向**：±X/±Y/±Z 快選按鈕，或輸入 dx/dy/dz（自動歸一化）。
- **規格**：額定推力、最小衝量（低於此值閥門不動作）、開關延遲、占空比上限、比衝。
- 可新增／刪除／停用；在 3D 視圖點選噴嘴會高亮對應卡片。

### 擾動與感測器
- 常值／隨機力矩：測試抗擾能力。重力梯度與太陽輻射壓：可選的環境力矩。
- 感測器誤差：開啟後控制器只看得到「有雜訊的估計值」，更接近真實。

## 圖表判讀

- **姿態**：三條線應收斂到目標角。
- **姿態誤差角**：總誤差線是重點；調變模式下會殘留 0.3–1° 的極限環（開關推力的固有現象，不是 bug）。
- **角速度**：收斂到 0。
- **力矩**：虛線（指令）與實線（實際）的差＝飽和與調變的影響。
- **RCS 開關歷程**：黃色階梯＝點火時段；觀察顫振（chattering）與占空比。
- **推進劑與 Δv**：推進劑單調遞減；Δv 是 RCS 淨力造成的平移速度變化。
- **相圖**：誤差 vs 角速度的軌跡；穩定系統的軌跡會螺旋狀拉向原點。提供「三軸軌跡」與「總量」兩種模式。
- **效能指標**：穩定時間、誤差統計、推進劑、控制能量、各推力器循環次數與累計點火。

**所有 2D 圖表**：滾輪縮放、拖曳平移、雙擊重設；游標懸停顯示數值。

## 三個預設案例

| 案例 | 想像對象 | 特點 |
|---|---|---|
| 小型 | 立方衛星級 | 慣量極小，最小衝量相對大 → 極限環較寬（帶寬設 1°） |
| 中型 | 上面級 | 預設均衡案例 |
| 大型 | 高慣量運載火箭 | 需要更大推力與更長時間 |

## 常見問題

- **跑一下就停住？** 模擬已達設定時長，按「重置」再跑，或加長「模擬時長」。
- **誤差不收斂？** 檢查推力器是否全被停用、推力是否相對慣量太小、或 PID 增益是否與案例（小型／大型）不匹配——套用對應預設即可。
- **PWPF 模式誤差停在 0.5° 附近？** 這是開關推力的極限環，屬正常物理現象；可用「理想連續」模式對照，或調小最小衝量。
- **想重現完全相同的結果？** 擾動面板的「隨機種子」固定即可。
- **想保留我的設定？** 側欄「匯出案例 JSON」；下次「匯入案例 JSON」還原。
